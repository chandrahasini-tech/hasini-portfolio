# Chadaram Chandra Hasini — Portfolio

A responsive, accessible, single-page portfolio for college evaluation. Open `index.html` in a browser or publish this folder as a static site. No build step is needed.

## Add your profile photo

1. Create an `images` folder beside `index.html`.
2. Save your photo there as `profile.jpg` (a square, well-lit head-and-shoulders photo works well).
3. In `index.html`, find the `profile-photo-placeholder` block.
4. Replace that whole block with:

   `<img class="profile-photo" src="images/profile.jpg" alt="Chadaram Chandra Hasini">`

5. Save and refresh the page. Keep the image file and website files together when you share or publish the site.
